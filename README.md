# Leela GPT Chat

Чат-игра по мотивам Лилы: игрок отвечает Мастеру, после каждого ответа автоматически бросается кубик, на время хода появляется векторная доска, затем включается анимация лотоса и появляется разбор клетки.

## Что есть

- Вход в игру только через выпадение 6.
- Один ответ игрока запускает один автоматический бросок.
- Доска появляется только во время броска, движения и переноса.
- Восходящие переносы подсвечиваются зеленым, нисходящие - золотым.
- Во время размышления Мастера показывается CSS-анимация лотоса без внешней GIF.
- Системный промпт Мастера встроен в страницу и передается backend endpoint.
- Если страница открыта как `file://`, работает локальная имитация ответов.

## Запуск

Откройте напрямую `outputs/leela-vector-game.html` в браузере.

Такой режим не требует сборки, сервера или внешних зависимостей.

Для настоящего общения с GPT запустите локальный сервер:

```powershell
$env:OPENAI_API_KEY="ваш_ключ"
node server.js
```

После этого откройте `http://localhost:4173`.

## Подключение GPT

В файле `outputs/leela-vector-game.html` есть константа `GPT_ENDPOINT`. По умолчанию она использует `/api/leela-chat`, когда страница открыта через сервер.

Endpoint должен безопасно хранить API-ключ и возвращать JSON:

```json
{ "reply": "текст ответа Мастера" }
```

Не кладите OpenAI API key прямо в HTML: при публикации на GitHub Pages он станет виден всем.
