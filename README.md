# Leela Vector Game

Векторная браузерная игра по мотивам Лилы: доска на 72 клетки, SVG-символы, фишка персонажа, кубик, движение по клеткам, зеленые подъемы и красные возвраты.

## Что есть

- 72 клетки с тематическими названиями и карточками смысла.
- Векторная доска с цветными планами, орнаментом, стрелами и возвратами.
- Выбор персонажа: странник, огонь, лотос или звезда.
- Анимированный кубик и короткий звук броска.
- GIF-анимация лотоса в боковой панели.
- Карточка текущей клетки с пояснением и переходом, если он есть.

## Запуск

Откройте `index.html` или напрямую `outputs/leela-vector-game.html` в браузере.

Проект не требует сборки, сервера или внешних зависимостей.
